# Yazid Hoblos — Portfolio

A responsive, static personal portfolio for GitHub Pages. No dependencies or build step. Open `index.html` in a browser to preview it.

## Personalize

Edit `index.html` to update the biography, projects, publications, experience, and contact details. Content is based on the supplied CV and matched public records; see `SOURCES.md` for provenance and verification limits. Colors and responsive layout live in `style.css`. Google Fonts is optional; system fonts are used when unavailable. The site works without JavaScript.

## Publish on GitHub Pages

1. Create a GitHub repository named `yazid-hoblos.github.io` under the matching GitHub account.
2. Upload these files to the root of the `main` branch, including `.nojekyll`.
3. In the repository's **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**, and save.
4. When deployment completes, visit `https://yazid-hoblos.github.io`.

This workspace has not been connected to a GitHub repository or published. Review the content before publishing.
